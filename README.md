🚗 Car Rental Web App

A responsive car rental website built using **HTML**, **CSS**, **JavaScript**, and **Bootstrap**.
This project allows users to browse available vehicles, view details, and book cars easily through an interactive UI.

 🌟 Features

- 🚘 Car listings with images, models, and rental prices
- 📅 Booking form for rental dates and user info
- 💰 Real-time pricing updates
- 📱 Responsive design using Bootstrap
- 🎨 Clean and modern UI

 Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
